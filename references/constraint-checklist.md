# 约束检查清单

只读取本次任务涉及的部分。以下是采集和判断框架，不是固定的规则数值表。

## 参数与证据

| 类别 | 按需核实的内容 | 缺失时的处理 |
| --- | --- | --- |
| 制造工艺 | 目标板厂、板层、铜厚、板厚、孔类型、最小线宽/间距、孔径、环宽、孔到铜/板边距离；确认当前工艺版本 | 先检查现有分配和明显冲突；制造下限标为待核实 |
| 电气条件 | 网络最大工作/瞬态电压、持续与峰值电流、允许温升、电压降、环境和导体所在层 | 不给“已满足载流/绝缘”的结论 |
| 网络用途 | 根据原理图/网表确认连接器电源、回流、开关节点、采样、逻辑、模拟和差分信号 | 不凭 `GND`、`VIN`、`SW` 等名称单独下结论 |
| 板上实际状态 | 工程和 PCB 标识、客户端版本、实际线宽/孔径、局部瓶颈、铺铜颈缩、网络类和区域规则 | 只报告已经读取的对象和范围 |
| 高速/差分 | 器件接口要求、板厂叠层、参考平面、阻抗目标、允许偏差及长度/偏斜限制 | 不把经验线宽当成阻抗计算结果 |
| 高压/绝缘 | 电压性质、工作环境、污染等级、海拔、材料、适用标准和认证目标 | 明确需要的设计输入；不要给通用爬电/电气间隙承诺 |

数值来源可来自用户明确给定的设计规范、实际选用器件数据手册、板厂工艺文件或适用标准。记录版本/日期和成立条件；示例值不能自动成为项目要求。

## 常见约束

| 约束 | 检查什么 | 常见误判 |
| --- | --- | --- |
| 线宽 | 规则的最小/默认/最大值、适用网络、实际最窄段、过渡到焊盘处、持续及峰值电流 | “板厂能做”被当成“这条电源线能承载电流” |
| 间距 | 不同对象对、同网/异网、铜与孔/板边、局部区域覆盖、高压条件 | 只看全局值，忽略网络间或区域规则 |
| 过孔 | 孔径、外径、成品孔与钻孔定义、环宽、工艺容差、连接层、实际回流路径 | 以单个过孔尺寸直接承诺载流能力 |
| 网络类 | 实际网络名、类成员、遗漏网络、规则分配到类还是单网络 | 已建类被当成规则已经生效 |
| 规则优先级 | 区域规则、网络间规则、网络规则及当前版本的覆盖机制 | 只修改低优先级规则却声称目标已生效 |
| DRC | 连接性、间距、线宽、孔及板边等已启用项目；检查对象和结果 | 关闭违规项后声称“全部通过” |

## 电机驱动与开关电源任务的附加核对

只有板中存在这些功能并且在请求范围内时才检查：

- 持续电流、峰值电流、开关电流和采样信号分别识别；相电流与输入电流不混用。
- 电流路径和回流一起核对，关注连接器、焊盘出口、过孔和铺铜窄颈；不只看某一段线宽。
- 按实际芯片布局指南检查开关回路、去耦、采样 Kelvin 连接及敏感信号与开关节点的关系。此类拓扑判断未必被普通 DRC 覆盖。
- 区分连接性证据、规则检查与通电测量。需要验证温升、波形或保护动作时写明具体尚缺的测试，不把离线结果称为硬件验证。
